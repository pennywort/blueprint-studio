# Файл проекта `*.blueprint.json` [owner 2026-10-15]

Экспорт: кнопка «Экспорт JSON» в редакторе (текущий граф, включая несохранённые
правки) или на карточке проекта на главной. Импорт: «Загрузить из JSON» на главной.
Файл = запись IndexedDB = `ServiceGraph` (`src/domain/model/service-graph.ts`) + `schemaVersion`.
Старые версии мигрируются при импорте (`infrastructure/persistence/graph-record-migration.ts`).

Разбор бага агентом: `npm run ui -- --url "http://localhost:3123/#/" --upload "[data-testid=project-import-input]=<файл>" --wait ".react-flow__node" …`

```text
schemaVersion        номер формата (сейчас 3)
id, title            id карты (ключ хранилища) и название
homePage?            Главная: id, orderIndex, elements[], faq?, additionalInfo?
subScenarios[]       подсценарии: id, type, title, description?, orderIndex, layerDepth?,
                     elements[], faq?, additionalInfo?, children?[] (вложенные)
applicationForms[]   формы: id, title, orderIndex, layerDepth?,
                     steps[]: id, title?, layerDepth?, elements[]
links[]              связи страниц: id, sourceElementId → targetId (подсценарий/форма)
logicRules[]         «Сложная логика»: правила видимости (selectList-вариант → элемент)
stepTransitions[]    переходы шагов формы: элемент шага (optionId?) → targetStepId

elements[] — общий union по kind:
  listItem / widgetCard   title, secondaryText?, icon?, image?, isRedirect?, redirectUrl?
  comment                 text, audience
  12 форм-компонентов     textField, infoBlock, datePeriod, attachment, checkbox,
                          configurationItemPicker, employeeSearch, selectList (options[]),
                          typography, button, addressPicker, employeeLoginField
  у всех: id; у большинства comment?, layerDepth? (явная колонка)
```
