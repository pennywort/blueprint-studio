## Жёсткие правила

1. **Одна задача за раз.** Бери задачи строго в порядке графа зависимостей (§5 декомпозиции). Не начинай следующую, пока критерий приёмки текущей не выполнен.
2. **Решения D1–D13 (§1) — не обсуждаются.** Если код противоречит решению — код неправильный.
3. **Архитектурные принципы §3 — обязательны:**
   - поля панели атрибутов не хардкодятся — только схемы (`IElementSchemaProvider` + проектные схемы, D4);
   - весь UI — из дизайн-системы Flamingo, включая иконки; самописный CSS только для canvas-специфики react-flow;
   - цвета только из объекта темы (D6), литеральные hex в компонентах запрещены;
   - все мутации графа — только через CommandBus (принцип 5);
   - границы слоёв из handoff §8.2 не нарушать (проверяет eslint-plugin-boundaries).
4. **После каждой задачи:** `npm run lint`, `npm run build` должны быть зелёными. Не зелёные — чини, не переходи дальше. Тесты не пишем и не запускаем [решение владельца 2026-10-10].
5. Координаты узлов не хранятся (D2). Порядок страниц — поле `orderIndex` у сущности (D13).
6. Закрытые вопросы в §6 (зачёркнутые) — это принятые решения, читай их. Открытые Q-1 и Q-3 тебя не блокируют: кнопки 3–4 тулбара — панели-заглушки, контракт микрофронтенда не трогай.

## Порядок старта (E0 — предпосылки)

Начинай с E0, задачи T-001 → T-002 → T-003 → T-004:

- **T-001 CommandBus** — `src/application/commands/`: интерфейс `Command` (execute/undo/redo), `CommandBus` на Immer `produceWithPatches`, команда `AddFormComponent` как референс. Критерий: тесты execute→undo→redo возвращают исходное состояние.
- **T-002 DI-контейнер** — `src/infrastructure/container.ts`: Awilix, `InjectionMode.PROXY`. Cradle: idGenerator, clock, elementSchemaProvider, commandBus. Подключение в `bootstrap.tsx`.
- **T-003 Фикс typecheck** — расхождение `FormStepSchema` vs `step.components` (6 ошибок `tsc --noEmit`). Форму решения смотри в handoff; если неоднозначно — спроси.
- **T-004 Доменная модель: страницы и связи** — страницы как коллекция верхнего уровня в ServiceGraph, поле `orderIndex`, модель связи elementId → subScenarioId с переназначением, Zod-схемы, unit-тесты.

Параллельно с E0 можно E1 (T-010 тема редактора → T-011 стилизация react-flow), если хочешь — но E0 важнее, оно блокирует всё остальное.
