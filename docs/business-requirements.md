## 2. Описание доработок

### AS IS

Функционал отсутствует в личном кабинете. Онбордер проектирует сервис в Pixso.

### TO BE

Реализовать создание архитектурной карты со сложной логикой в личном кабинете владельца сервиса с расширенным набором элементов.

---

## 3. Основной концепт

### 3.1. Процесс

- **Отдельный этап** заказа/изменения МИПа (не продолжение Лайт). Запускается после согласования БТ, когда сервис требует сложного дизайна.
- **Заменитель Pixso**, управляемый через стикеры. Проектирование — прямо в личном кабинете.
- **Предпросмотр** — конвертирует стикерную схему в визуальную форму (компоненты) для онбордера и владельца.
- Стикеры содержат: название компонента, логику, плейсхолдеры, характеристики.

### 3.2. Доступ

| Стадия      | Доступ                                             |
| ----------- | -------------------------------------------------- |
| **MVP**     | Только онбордеры                                   |
| **Целевое** | Владельцы продуктов                                |
| **Пилот**   | Решение об расширении — после пилота на онбордерах |

### 3.3. Область применения

- Инструмент — **для сервисов**.
- **Старые сервисы** — доработка по процессу (Pixso-заменитель с полной отрисовкой или по частям сценария).
- **Последующие доработки** фронтенда — через инструмент (если сервис создан в Pixso-заменителе).

### 3.4. Результат работы

Структурированная инструкция (описание визуализации сервиса), а не готовый код. Цифровой аналог разрозненных архитектурных карт.

## 4. Маршрутизация и работа с правками

### 4.1. Логика

- Логика маршрутизации (зависимости, значения) — в технических характеристиках, не в визуальной форме.

### 4.2. Возврат на доработку

Разработчик отклоняет заявку обратно на онбординг при обнаружении несоответствий (забытое поле, плейсхолдер, ошибка).

**После передачи в разработку:**

- ❌ Кардинальные изменения визуальной формы запрещены.
- ✅ Только минорные правки.

### 4.3. Два пути возврата (онбордер)

| Тип правок        | Действие                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------ |
| **Нерадикальные** | Онбордер правит сам (комментарий разработчику, исправление текста) без изменения структуры |
| **Радикальные**   | Переход к владельцу для пересогласования                                                   |

## 5. UI конструктора

### 5.1. Верхняя панель

**Назначение:** глобальные действия со сценарием и контроль версий.

| Элемент          | Поведение                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сохранить**    | Всегда активна. Сохраняет наработки, показывает snack-bar с подтверждением                                                                                          |
| **Предпросмотр** | Открывает эмулятор МИПа (рендеринг сценария в форму)                                                                                                                |
| **Согласование** | Запуск валидации владельцем. Если есть несохранённые изменения — диалог «Сохранить перед отправкой?». Смена статуса на «На согласовании», блокировка редактирования |

### 5.2. Левая панель

**Назначение:** выбор контекста редактирования (иерархический список).

| Элемент                           | Описание                                                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Выбор областей**                | TreeView: Главная, Подсценарий, Форма заявки. При выборе — дропдаун с наполнением                            |
| **Выбор элементов**               | Список атомарных UI-компонентов для выбранной области (кнопки, текст, изображения, инпуты). Реализация: Drop |
| **Выбор элемента для разраба**    | Элемент для комментария разработчику                                                                         |
| **Выбор предпросмотра структуры** | Переключатель режима: логические связи (стрелки между формой и компонентами)                                 |
| **AI**                            | Заглушка. Tooltip: «Тут скоро появится AI-ассистент»                                                         |

### 5.3. Нижняя панель

**Назначение:** управление зумом, позицией и режимом просмотра. Пристыкована к нижнему краю.

| Элемент                           | Описание                                                                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Блок перемещения**              | Кнопки: undo, redo                                                                                              |
| **Кнопка расширения экрана**      | Меняет иконку на «Свернуть» при активности                                                                      |
| **Масштабирование (Zoom)**        | Слайдер или кнопки `+` / `-`. Шаг 10% (25%–200%). Двойной клик на цифру = сброс к 100%                          |
| **Мини-окно навигации (Minimap)** | Окно в углу холста. Прямоугольник viewport. Перетаскивание для быстрого скролла. Вкл/выкл — открытием/закрытием |

## 6. Зоны проектирования

Конфигурируемые зоны: **Главная**, **Подсценарий**, **Сценарий**.

### 6.1. Главная страница (одна шт.)

Доступные элементы:

| Элемент                       | Описание                                                                      |
| ----------------------------- | ----------------------------------------------------------------------------- |
| **List-item**                 | Основной + доп. текст, иконка (или без), редирект в новой вкладке             |
| **Widget card**               | Основной + доп. текст, иконка/иллюстрация (или без), редирект в новой вкладке |
| **FAQ**                       | Частые вопросы (см. 6.2)                                                      |
| **Доп. информация о сервисе** | См. 6.3                                                                       |

#### Настройки List-item

- Основной и дополнительный текст.
- Иконка из перечня (или без).
- Ссылка-редирект (новая вкладка).

#### Настройки Widget card

- Основной и дополнительный текст.
- Иконка/иллюстрация из перечня (или без; предстоит решить: готовый набор vs загрузка своих).
- Ссылка-редирект (новая вкладка).

### 6.2. FAQ (частые вопросы)

- Настройки в атрибутном окне элемента.
- **CSV:** загрузка/выгрузка. Шаблон в интерфейсе. Функция динамического контента.
- **Фильтрация:** при >10 вопросов — автоматический поиск.
- **Теги:** группировка по тегам. Фильтры по тегам в поиске.
- **Кнопки на сценарий:** связка с формой заявки, поле вопроса.

### 6.3. Доп. информация о сервисе

- Горячие ссылки на мапп, СберЧат и др.
- Иконки, основной/доп. текст, доступность сегментов.

### 6.4. Подсценарий (разводящая страница)

Элементы: List-item, FAQ, доп. информация о сервисе.

### 6.5. Форма заявок

- Форма для каждого сценария (своя / общая для нескольких / для всех).
- Drag-and-drop компонентов на рабочее пространство.
- Область автоматически расширяется.
- Компоненты перемещаются внутри формы.
- **Шаги:** горизонтально (слева направо), количество не ограничено. При N шагах — предпросмотр. Новый шаг автоматически вставляется справа.

## 7. Типы сценариев (list-item)

| Тип                                    | Поведение                                                 |
| -------------------------------------- | --------------------------------------------------------- |
| **Сценарий-заявка**                    | Открывает форму создания заявки                           |
| **Сценарий-ссылка**                    | Редирект по ссылке (инструкции, переход в другие сервисы) |
| **Навигационный сценарий (контейнер)** | Следующий уровень вложенности. Вложенность не ограничена  |

**Атрибуты сценария:**

- Название (обязательно)
- Описание / secondary text (необязательно)
- Иконка (необязательно)
- Для навигационного: информационный блок справа внутри
- Для ссылки: ссылки по домену/устройству

## 8. Компоненты формы заявки

### 8.1. Текстовое поле

**Назначение:** ввод короткого/длинного текста (вопросы, описания, номера заявок).

| Атрибут                  | Описание                                                      |
| ------------------------ | ------------------------------------------------------------- |
| **Название (Label)**     | Произвольный текст над полем, редактируемый                   |
| **Обязательность**       | Обязательное / необязательное                                 |
| **Многострочность**      | Однострочное / многострочное (авторасширение)                 |
| **Ограничение символов** | Макс. число символов (необязательно, на усмотрение онбордера) |
| **Placeholder**          | Текст до начала ввода                                         |
| **Caption**              | Подсказка под полем (формат, счётчик символов)                |
| **Tooltip**              | Иконка `i` с подсказкой при наведении                         |
| **Маска ввода**          | ⏳ Отложено. Сейчас — простой текст без маски                 |

**Условия:** многострочное = авторасширение; ограничение = целое число.

### 8.2. Информационный блок

**Назначение:** статический текстовый блок для пояснений, инструкций, ссылок.

| Атрибут                  | Описание                                           |
| ------------------------ | -------------------------------------------------- |
| **Текст**                | Основной контент + гиперссылки                     |
| **Цвет полоски**         | ❌ Не добавлять. Только один цвет (зелёный/мятный) |
| **Ограничение символов** | ❌ Убрать. Текст произвольной длины                |
| **Динамический контент** | На усмотрение онбордера                            |

**Условия:** одностильный (зелёная полоса слева), только текст + ссылки, без картинок.

### 8.3. Дата / период

**Подтипы:** Дата (одна) / Период (с — по).

| Атрибут                    | Описание                                       |
| -------------------------- | ---------------------------------------------- |
| **Название**               | Произвольное                                   |
| **Обязательность**         | Да / нет                                       |
| **Время**                  | Дата + время (вкл/выкл)                        |
| **Нельзя выбрать прошлое** | Запрет дат раньше текущей                      |
| **Нельзя выбрать будущее** | Запрет дат позже текущей                       |
| **Другое**                 | Пользователь описывает логику в свободное поле |

**Период:** каждая дата настраивается отдельно. Ограничения — относительно текущей даты.

### 8.4. Вложение

**Назначение:** прикрепление файлов к заявке.

| Атрибут                | Описание                                                                      |
| ---------------------- | ----------------------------------------------------------------------------- |
| **Название**           | Произвольное                                                                  |
| **Обязательность**     | Да / нет                                                                      |
| **Типы файлов**        | Форматы (.docx, .pdf, .xlsx), настраиваются онбордером                        |
| **Количество файлов**  | Любое в пределах лимита платформы (настройка «только 1» / «до N» — в будущем) |
| **Макс. размер файла** | Лимиты платформы (~3 МБ/файл, ~50 МБ суммарно), не настраивается              |
| **Caption**            | Автоподсказка из выбранных атрибутов (не редактируется вручную)               |

**Условия:** вложение — **только один раз** в форму.

### 8.5. Чекбокс

**Назначение:** одиночный флажок для подтверждения условий.

| Атрибут                  | Описание                                 |
| ------------------------ | ---------------------------------------- |
| **Название**             | Текст рядом с чекбоксом                  |
| **Обязательность**       | Обязательный выбор для отправки формы    |
| **Динамический контент** | ❌ Запрещён, если завязана маршрутизация |

**Условия:** одиночный. Если обязательный — без галочки форма невалидна.

### 8.6. КЭ (Конфигурационная единица)

**Назначение:** выбор из серверного справочника.

| Атрибут                      | Описание                                                         |
| ---------------------------- | ---------------------------------------------------------------- |
| **Название**                 | Произвольное                                                     |
| **Обязательность**           | Да / нет                                                         |
| **Мультивыбор**              | Да / нет                                                         |
| **Набор отображаемых типов** | Онбордер выбирает нужные справочники из общего списка            |
| **disabled**                 | Поле недоступно для ввода                                        |
| **tooltip**                  | Всплывающая подсказка                                            |
| **required**                 | Признак обязательности                                           |
| **emptyResult**              | Текст при отсутствии результатов (по умолчанию: «КЭ не найдены») |
| **helperText**               | Подсказка                                                        |
| **disableCloseOnSelect**     | Закрывать поле после выбора                                      |

**Условия:** источник — серверный справочник. Можно скрыть неиспользуемые категории.

### 8.7. ФИО (Поиск сотрудника)

**Назначение:** выбор сотрудника (внутренний клиент / коллега).

| Атрибут            | Описание                                                                  |
| ------------------ | ------------------------------------------------------------------------- |
| **Название**       | Произвольное                                                              |
| **Обязательность** | Да / нет                                                                  |
| **Тип выбора**     | «Коллеги» (внутренний контур) / «Все сотрудники» (расширенный справочник) |

**Условия:** автокомплит, не текстовый ввод. Не влияет на маршрутизацию (если не привязан к созданию заявки).

### 8.8. Список выбора

**Назначение:** выбор одного/нескольких значений из списка.

| Атрибут             | Описание                                            |
| ------------------- | --------------------------------------------------- |
| **Название**        | Произвольное                                        |
| **Обязательность**  | Да / нет                                            |
| **Тип отображения** | Радио-группа / Чекбоксы / Выпадающий список / Чипсы |
| **Мультивыбор**     | Да / нет (радио — всегда один)                      |
| **Варианты**        | Display Name + Value + По умолчанию                 |
| **Поиск**           | Автокомплит при большом списке                      |

**Условия:**

- Радио-группа — **макс. 5 вариантов**. При нарушении — предупреждение.
- Чекбоксы/чипсы — рекомендуется ≤7–10.
- Выпадающий список (>10 значений) — autocomplete.
- Динамический контент / маршрутизация — если маршрутизация, компонент **запрещён**.
