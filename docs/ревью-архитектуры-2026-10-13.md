## 3. Производительность (стенд `stress.html`, prod-сборка, Chromium)

Граф стенда по умолчанию: 121 узел, 1105 карточек, 495 рёбер. Демо — 4 узла, 17 карточек.

| Действие                   | Демо          | Стенд                         |
| -------------------------- | ------------- | ----------------------------- |
| Загрузка до простоя        | 3.4 с         | **30 с**, long task до 11.6 с |
| Выделить карточку          | 57 мс         | **3.3 с**                     |
| Ввод 1 символа в атрибутах | ~45 мс        | **~3.2 с**                    |
| Команда (undo, «+ шаг»)    | ~80 мс        | **3.5–4 с**                   |
| Pan / zoom                 | без long task | без long task                 |

Причины (профиль CPU + счётчик раскладок):

1. Любое изменение графа или размеров → `computeLayout` → `graphToFlow` строит **все** узлы заново → кэш
   узлов промахивается → перерисовываются все 121 узел, 1105 MUI-карточек и 495 рёбер.
2. Петля измерений: размеры от react-flow приходят пачками → новый `measuredSizes` → полная раскладка
   и полный ререндер → новые измерения. На загрузке стенда — 44 раскладки (dev, StrictMode).
3. `FormNode` вызывает `updateNodeInternals` на каждое новое `data.steps` (а оно новое при каждом
   пересчёте) — повторное измерение всех форм.
4. Тяжёлая карточка: MUI v4 Card/CardContent/Typography/Chip/Box (`makeStyles`) ×1105.
5. Ввод в панели атрибутов — команда на каждое нажатие (см. A10) → п.1.

Предложения (по убыванию эффекта):

- P1. Структурное разделение в `graphToFlow`: `WeakMap` «объект страницы immer → узел» — неизменённые
  страницы сохраняют идентичность узла; позиции — отдельно от `data`.
- P2. Раскладка по измерениям — один проход: собирать размеры за кадр (rAF), пересчитывать позиции
  только при изменении высоты колонки; не пересоздавать `data` при смене позиции.
- P3. Выделение/цель связи — не через `data` (см. A4), `ElementCard` в `React.memo`.
- P4. `updateNodeInternals` — только при смене набора handles (ключ из вариантов и правил).
- P5. Буфер ввода в атрибутах + debounce/blur (см. A10).
- P6. `onlyRenderVisibleElements` у ReactFlow + упрощённая карточка (div + классы темы) при zoom < 0.5.
