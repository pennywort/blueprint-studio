# R4 — чистка долга (мелкое, механическое)

Контекст: `docs/ревью-архитектуры-2026-10-13.md` (A5–A9, A11–A13). Поведение не меняется.

1. A5: один модуль домена для обходов — `walkPages`, `walkSubScenarios`,
   `findOwnerPageId`; убрать 7 копий (`graph-lookup`, `element-containers`,
   `connection-rules`, `single-root-level`, `graph-depths`, `canvas-layout`, адаптер).
2. A6: тип страницы с дискриминатором вместо `(page as { layerDepth?: number })`;
   id приводить только через `to*Id`, без `as ElementId` и т. п.
3. A7: убрать хвосты до ADR-17 — `dndKind`, `ELEMENT_DND_KINDS`, `movableKinds`,
   `acceptsKind`, вид элемента в MIME-типе; «component» → «element» в именах
   (`FormComponentRef`, `findFormComponent`).
4. A8: общий хук `useElementDropZone` + общие стили узла для `ScenarioNode` и `FormStepLayers`.
5. A9: не писать во внутренний стор xyflow (`store.setState({ connectionClickStartHandle })`)
   — публичный API; id перетаскиваемого — модульное состояние текущего drag вместо
   MIME-типа в нижнем регистре.
6. A12: `CommandBus.execute` возвращает результат `produceWithPatches`, без повторного `applyPatches`.
7. A11: миграция legacy-формата — из `z.preprocess` доменной схемы в адаптер хранилища
   с номером версии схемы.
8. A13: удалить код сжатия T-033, если владелец не против (сейчас выключен флагом) — спросить.

Проверка: `npm run verify`, `npm run rules`, `npm run ui` (dnd элементов, связи, клик-связь, Esc).
