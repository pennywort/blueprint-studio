# R1 — единое правило навигационной связи — ✅ ВЫПОЛНЕНО 2026-10-14

Контекст: `docs/ревью-архитектуры-2026-10-13.md` (A2).

Решение владельца [owner 2026-10-14]: связь можно провести на блок **любой колонки правее**
источника; при этом цель **переносится в соседнюю колонку** (уровень источника + 1).

Сейчас: подсветка (`domain/connection-rules.ts`) разрешает любую колонку правее, но
`ConnectElements` → `placeLinkTargetIntoNextLayer` не переносит цель с явным `layerDepth`
(а он есть почти у всех блоков) → остаётся связь «через уровень», которую потом молча
удаляет каскад N4 в `MoveElement`/`SetPageLayerDepth`.

Сделать:

1. `ConnectElements` и `ReconnectElements` проверяют цель тем же доменным правилом, что и
   подсветка (`connectableTargets`); недопустимая цель — ошибка команды (снекбар).
2. После создания/переназначения связи цель всегда встаёт на уровень источника + 1
   (явный `layerDepth`), в конец колонки (orderIndex, D7).
3. Связи самой цели, ставшие несмежными, — тот же каскад N4, что в `SetPageLayerDepth`
   (вынести его в общую функцию, сейчас он скопирован в `MoveElement`).
4. Undo возвращает всё одной командой.

Проверка: `npm run verify`, `npm run rules`; `npm run ui` — связь Главная → блок через
2 колонки: блок переехал в колонку 1, связь видна; перенос любого элемента её не удаляет.
