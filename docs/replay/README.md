# docs/replay — пакет для агента

Назначение: сгенерировать 28 OpenSpec-changes для уже готового кода (по одному на задачу), с привязкой номеров задач в commit-сообщениях.

- `INSTRUCTIONS.md` — строгий протокол (агент читает в начале каждой сессии).
- `PROGRESS.md` — журнал: статус 28 changes, текущий шаг.
- `COMMIT-REFS.md` — номера T-xxx / ADR / D для commit-сообщений.
- `cards/PR-NN-<id>.md` — по карточке на change (агент читает только текущую).
- Обоснование и общий план: `../план-pr-openspec.md`.

Использование: скопировать папку в целевой репозиторий как `.replay/` (добавить в `.gitignore`), в Qwen сказать:
«Продолжи по `.replay/INSTRUCTIONS.md`». После каждого change агент просит очистить контекст (`/clear`) и повторить фразу.
