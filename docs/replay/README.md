# docs/replay — пакет для агента (скопировать в новый репозиторий как `.replay/`)

- `INSTRUCTIONS.md` — строгий протокол сессий (читает агент в начале каждой сессии).
- `PROGRESS.md` — журнал: статус каждого из 28 PR, текущий шаг, заметки, журнал сессий.
- `cards/PR-NN-<id>.md` — по одной карточке на PR (агент читает только текущую).
- План и обоснование: `../план-pr-openspec.md`.

Использование: `cp -r docs/replay /путь/к/новому/репо/.replay`, затем в Qwen: «Продолжи по `.replay/INSTRUCTIONS.md`».
После каждой сессии агент просит очистить контекст (`/clear`) и повторить эту же фразу.
