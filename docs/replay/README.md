# docs/replay — пакет для агента (33 OpenSpec-changes по готовому коду)

- `INSTRUCTIONS.md` — протокол сессий. Агент читает его в начале каждой сессии.
- `tasks/NN-<id>.md` — 33 задачи: цель, состав, номера, мелочи, «не входит», где проверять по коду.
- `PROGRESS.md` — журнал статусов и текущая задача.
- `COMMIT-REFS.md` — номера T-xxx / ADR / D / R для commit-сообщений.

Запуск:

1. Скопируй папку в целевой репозиторий как `.replay/` и добавь её в `.gitignore`.
2. Скажи агенту: «Продолжи по `.replay/INSTRUCTIONS.md`».
3. После каждой задачи агент просит `/clear` и повторить эту фразу.

Инфраструктура агентов (`.claude/`, `.qwen/`, `scripts/agent/`, `AGENTS.md`, `CLAUDE.md`, `QWEN.md`, `PROJECT_STATE.md`) — это не продукт, задач на неё нет.
Задач без кода (планы в `docs/refactoring/` со статусом «ожидает») тоже нет.
Список задач сверен с `master` на 2026-10-26.
