## Цель

Каждое правило редактора задаётся строкой таблицы в одном месте (конституция §4a).

## Состав (что реализовано и должно попасть в change)

- Реестр видов элементов element-kinds (что умеет вид)
- Возможности блоков таблицей (что блок принимает, включена ли логика)
- Лимиты { kind, scope, max } и строгость (error / warning / off) — rule-policy
- Единый словарь подписей видов элементов и узлов
- EditorRules — единый объект правил

## Не входит (не описывать)

- Внешний конфиг правил и настройки администратора — задача editor-settings-registry.
