# Задача 14 — Добавление и удаление блоков, уровни

| Поле                         | Значение                   |
| ---------------------------- | -------------------------- |
| change id                    | `canvas-add-remove-blocks` |
| Эпик                         | 002                        |
| Номера (T-xxx / ADR / D / R) | T-034, ADR-11, ADR-19      |
| Реальные коммиты (справка)   | 30fcae6, a0c14f8, cbfcf09  |

## Цель

Блоки добавляются и удаляются, уровни блоков управляются и ограничены по ёмкости.

## Состав (что реализовано и должно попасть в change)

- T-034 добавление блоков и элементов из тулбара, удаление, каскады
- Новый блок — на следующем уровне; перенос блока между уровнями dnd с подсветкой (SetPageLayerDepth, ADR-11)
- Ёмкость уровней — таблица «уровень → max узлов», общая для страниц и шагов; заполненный уровень подсвечивается запретом (ADR-19)
- Блок, потерявший связи, остаётся на своём уровне

## Не входит (не описывать)

- Автосжатие узлов T-033 (удалено). ADR-15 (superseded ADR-19).
