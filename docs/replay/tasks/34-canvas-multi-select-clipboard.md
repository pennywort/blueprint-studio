# Задача 34 — Мультивыделение элементов, копирование и перенос группы

| Поле                         | Значение                        |
| ---------------------------- | ------------------------------- |
| change id                    | `canvas-multi-select-clipboard` |
| Эпик                         | 002                             |
| Номера (T-xxx / ADR / D / R) | ADR-12, ADR-22, R-HK            |
| Реальные коммиты (справка)   | 7d01288, 2536c2c, cc64e19       |

## Цель

Архитектор набирает несколько элементов Shift+кликом и копирует, вырезает,
вставляет или удаляет их одной операцией.

## Состав (что реализовано и должно попасть в change)

- Shift+клик по карточке элемента (и варианту Select) добавляет элемент в выделение или убирает из него; обычный клик — выделение одного
- Набор может включать элементы разных блоков; последний выбранный — основной
- Ctrl+C копирует набор в буфер редактора в порядке карты (блоки — в порядке выбора, внутри блока — по месту в списке)
- Ctrl+V вставляет все копии под новыми id в конец блока основного элемента; без выделенных элементов — в выделенный узел/шаг; копии становятся выделенными
- Вставка при выделенных скопированных элементах кладёт копии в тот же блок
- В шаге формы вставленные элементы встают в одну новую колонку правее самой глубокой
- Delete/Backspace и Ctrl+X удаляют весь набор; вставка и удаление группы — одна команда, один шаг undo (AddElement / RemoveElement принимают несколько элементов)
- Панель атрибутов показывается только при одном выделенном элементе
- Перетаскивание карточки из выделенной группы переносит всю группу (в т.ч. из разных блоков) подряд, в порядке карты, на место якоря — одной командой MoveElement, один шаг undo; бросок на карточку самой группы оставляет её на месте
- Нажатие на карточку группы группу не сбрасывает (её тащат целиком); клик без переноса оставляет выделенной одну карточку
- Копируются только сами элементы: связи, правила «Сложной логики» и переходы шагов не переносятся на копии (ADR-22)
