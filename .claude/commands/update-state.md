description: Обновить PROJECT_STATE.md по проверенным фактам
---

Аргументы владельца (источник `[owner YYYY-MM-DD]`, если есть): $ARGUMENTS

1. Прочитай SCHEMA RULES (строки 1–30 `PROJECT_STATE.md`; файл целиком не читать — `npm run state:summary`, секции — `npm run state:section -- <id>`), соблюдай буквально (структура секций и шапки таблиц не меняются, статусы — из enum'ов).
2. `npm run state:check` — механические расхождения. Факты — только из закоммиченного (git, package.json, `src/`) и слов владельца.
3. Правь только то, что расходится: §4.1/§4.2, §3 (новый ADR = max+1), §6, §7 (выполненное удаляется), §8. Если всё совпадает — ничего не меняй.
4. Покажи `git diff PROJECT_STATE.md` с источником каждого факта и спроси «Применить?».
5. После «да» — строку в CHANGELOG и бамп даты добавляет ТОЛЬКО скрипт: `npm run state:log -- agent:claude "<кратко что изменилось>"` (вручную §9 и UPDATED не трогать).
